*vc-jwt-decoder.txt*  Decode and verify JWTs and Verifiable Credential JWTs

==============================================================================
CONTENTS                                              *vc-jwt-decoder*

Decodes JWT / VC-JWT / VP-JWT tokens with the `vc-jwt-decoder` Python CLI and
shows header, payload, enveloped VCs and signature status in a split.

Requirements: Neovim 0.10+, and the CLI:
>sh
    uv tool install 'vc-jwt-decoder[cli]'
<
Without it, `uvx` is used if available. Check with |:checkhealth|.

==============================================================================
COMMANDS                                         *vc-jwt-decoder-commands*

                                                              *:JwtDecode*
:[range]JwtDecode[!] [{token}]
    Decode {token}, or the lines in [range] (default: whole buffer).
    With [!] the signature is not verified (no network access).

                                                        *:JwtDecodeCursor*
:JwtDecodeCursor[!]
    Decode the token under the cursor. Surrounding quotes, commas and a
    "Bearer" prefix are ignored.

==============================================================================
MAPPINGS                                         *vc-jwt-decoder-mappings*

No mappings are set by default.

<Plug>(JwtDecodeCursor)       Normal mode: decode token under cursor.
<Plug>(JwtDecodeSelection)    Visual mode: decode the selection.
>lua
    vim.keymap.set("n", "<leader>jd", "<Plug>(JwtDecodeCursor)")
    vim.keymap.set("x", "<leader>jd", "<Plug>(JwtDecodeSelection)")
<
In the result buffer, `q` closes the window and `r` lays the panels out
again for the current window width.

==============================================================================
RESULT VIEW                                        *vc-jwt-decoder-view*

The result opens beside the current window and shows the CLI's formatted
output: a panel each for the header and payload, with the signature status
and key details in the payload panel's title, and the same for every
enveloped VC. When a signature check fails, its steps follow the panels.

It is a normal read-only buffer: the CLI's colors become highlights and its
background colors are dropped, so the colorscheme's background shows through.
The panels are laid out for the window width at the time they open; resizing
the window does not change them. Press `r` to run the CLI again for the
current width, `q` to close the window.

==============================================================================
CONFIGURATION                                     *vc-jwt-decoder-config*
>lua
    require("vc-jwt-decoder").setup({
      cmd = nil,           -- command list; nil = auto-detect
      verify = true,       -- verify signatures
      auto_open = true,    -- decode *.jwt files on open
      split = "vertical",  -- "vertical" | "horizontal" | "tab"
    })
<
Calling setup() is optional.

==============================================================================
LUA API                                              *vc-jwt-decoder-api*

require("vc-jwt-decoder").decode({token}, {opts})
require("vc-jwt-decoder").decode_range({line1}, {line2}, {opts})
require("vc-jwt-decoder").decode_cursor({opts})
require("vc-jwt-decoder").decode_selection({opts})

{opts} is an optional table: `{ verify = boolean }`.
